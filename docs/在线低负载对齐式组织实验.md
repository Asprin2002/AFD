# 在线低负载实验:对齐式子批组织(仿 CHIME)+ joint 策略

> 生成日期：2026-09-28
> 数据来源：`results/full-joint-qwen-coder-stable-alignment/` 三个 checkpoint json(均为随后本次运行输出,非机制预测)
> 术语：对齐式(仿 CHIME)组织 = 静态异质矩阵里验证过的调度器:先用"最长处理时间优先"做初始分组,再在两边人数、每卡副本均衡的约束下反复交换请求对,最小化"一个子批在 PIM 上做注意力、另一个子批在 GPU 上做稠密算子"的流水线不匹配。LPT = 最长处理时间优先(现已退役,本实验不跑)。

---

## 1. 目的

- 在线 `joint`(联合调度)策略之前一直用 LPT 组织子批,而 CHIME 基线用自己的配对,1.10x 无法归因。
- 本次把**所有策略臂统一换成对齐式(仿 CHIME)组织**,在**低于设备容量的稳定负载**上重跑,回答:
  - 同一种组织方式下,联合策略(joint)相对不做任何迁移的对照(control)能拿到多少收益;
  - 换成对齐式组织后,相对 CHIME 基线的总收益是多少。

## 2. 设置(为什么是这个负载)

- **设备**：GPT-175B / 8×A100 + DIMM-PIM;已观测稳定持续吞吐 ≈ 106–117 token/s。
- **负载**：`qwen-coder-stable-512.csv`,是 512 请求 Qwen-Coder trace 的**时间轴缩放版**——到达间隙整体放大 58.3 倍,供给从原生 ≈4,491 token/s 降到 ≈**77 token/s(≈0.7 × 容量)**,请求长度与相对到达结构不变。原因:原生 trace 对单副本设备过载约 40 倍,原样重放测的是排空压力不是稳态服务。
- **三臂**(同一 trace,`max_batch=64`,FCFS 接纳):

| 臂 | 组织方式 | 做的事 |
| --- | --- | --- |
| chime_baseline | CHIME 自带 N=1 配对 | 形式参照(所有 KV/注意力在 PIM,GPU 只做稠密算子) |
| control(对齐式) | 对齐式 | 与基线相同的放置,但分子批用对齐式 |
| joint(对齐式) | 对齐式 | 对齐式组织 + 合法(KV 写入端/算子)联合调度,可迁移 |

## 4. 结论与机制归因

- **在低负载下,联合调度是正收益但很薄(~1.1–1.5%)**,而且为此付出了 **976 次 KV 切换 + 358 次算子切换**的高频迁移。
- **机制能完全解释**:三臂的 GPU 路径利用率都高达 **0.971–0.972**——即使平均并发只有 7.6,一个解码步的时长已经被"GPU 稠密算子(QKV/O/FFN)+ GPU 注意力"这条路径占满。联合策略把未来-KV 写到 GPU 是在一个**已被稠密算子占满的 GPU** 上再加注意力负载,"GPU 容量允许卸载比例"这个收益乘子几乎为零。这与静态矩阵的收益公式一致:**收益 ≈ 注意力压力 × GPU 卸载头部空间 × (1 − PIM 固定载荷)**;低负载先天没有大注意力压力也没有 GPU 头部空间。
- 对比高负载原生 512(P95 −8.4%,吞吐 +9.8%):**高负载下大并发(batch≈38)才给出可观收益,但那不是稳态服务区;低负载稳态区(单副本设备真正该服务的地方)收益只有 ~1%**。这是本次实验最重要的诚实结论。
- 额外的运维观察:低负载下策略会高频来回切换(976+358 次),若计真实迁移成本,净收益还要再打折;值得做停留时长/最少驻留约束的敏感性检查。

## 5. 一致性校验

- 三臂 `model_code_sha256`、`runner_code_sha256`、`trace_sha256` 全同,`status=completed`,512 请求全部完成、输出 token 守恒(404,016,运行器内建校验通过)。
- `chime_baseline` 臂的组织方式保持 `fixed`(基线固有配对),`control`/`joint` 用对齐式——配置逐臂确认无误。
- smoke 阶段在 32 请求 BurstGPT `short-long-r85` 上验证了对齐式分支端到端可跑(token 守恒 OK),且该近同质请求集上对齐式 == LPT(同前静态矩阵的退化现象)。

## 6. 诚实边界与下一步

- 本实验只有一个负载档位(≈0.7 × 容量)。低负载 → 薄收益的结论只对"并发≈8"有效;**中负载(batch≈16–32,仍稳态)**正是静态甜区,尚未在这个 trace 上验证。
- 976/358 次切换的量级说明低负载下策略产生了大量低价值迁移;下一步最有价值的是给策略加**最少驻留/切换惩罚敏感度**检查,防止在薄收益区空转。
- 对齐式 vs 已退役 LPT 的直接对比不跑了(用户决定),所以本报告**不声称组织方式本身带来 N% 增益**。
